# Execution Instructions

Follow the steps below to run the LeetCode Question Difficulty Predictor on a Windows system using PowerShell.

## Prerequisites

Make sure Python and Git are installed on your system.

The project uses the following Python libraries:

- Streamlit
- Pandas
- Scikit-learn
- SciPy
- Joblib

## Command Sequence

Open PowerShell and execute the following commands in order:

## Step 1: Clone the Repository

git clone https://github.com/shivamkishorr/LeetCode-Question-Difficulty-Predictor.git

##Step 2: Navigate to the Project Folder

cd LeetCode-Question-Difficulty-Predictor

## Step 3: Install Required Libraries

pip install streamlit pandas scikit-learn scipy joblib

## Step 4: Run the Streamlit Application

streamlit run app.py

If Streamlit is not recognized, use:

python -m streamlit run app.py

## Step 5: Open the Application

Click on URL
